# OFFSET COUNT: INSTRUCTIONS
# Replace COUNT stock instruction words at OFFSET (lk payload) with our instructions.

# Orange-state warning screen (f_05b948, unlocked device): clear the screen,
# print "Orange State" and "OS Not Being Verified Or Custom OS. Dismiss After
# 5 Seconds.", show it, wait 5 s -> our wait with only the menu countdown
# (menu entry point). The stock code after it shows the screen and goes on booting.
05b974 17: bl t70_orange_wait

# Fastboot command loop (f_007b4c): its call for the idle timeout (f_00509c,
# always 0) -> stop the hardware watchdog, which nothing restarts while
# fastboot waits (src/fastboot.c), and return 0 as before.
007ba0 1: bl t70_fastboot_start

# USB interrupt handler (f_057184), standard request CLEAR_FEATURE(ENDPOINT_HALT):
# the stock code reads the endpoint index register (0x1120000e) into x8 and
# then writes the endpoint number to the address it just read (0..15) instead
# of to the register: a data abort and a reset. The macOS fastboot sends this
# request whenever it opens the device. Save the index in w11, select the
# endpoint in the register, keep the saved index in w8 as the code after
# expects (it restores the register from w8).
057c10 3: ldrb w11, [x8]; strb w10, [x8]; mov w8, w11

# Boot mode check (f_00d3d0): a volume key held at power-on no longer picks
# the mode (volume down: recovery, volume up: factory); it opens the boot
# menu instead, which has both. Recovery through the misc message or the RGU
# boot mode is unchanged. The earlier check at 0xd424 only logs the key.
00d464 1: mov w0, wzr
00d4a0 1: mov w0, wzr
